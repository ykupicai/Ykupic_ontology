# 一定規模以上或性質特殊土地申請使用許可認定標準 重點

> **這部是什麼**：判斷國土計畫新制下，一筆申請案是否達到**須申請使用許可**門檻的認定標準。全 9 條。
> 是 [[國土計畫使用許可申請辦法-重點]] 四支柱之一——**先用本標準判斷「要不要走使用許可」**，
> 確定要走了才進入申請辦法的程序。

## 一、★ 基本面積門檻（第三條）——依國土功能分區分流

| 國土功能分區 | 一定規模以上門檻 |
|---|---|
| **國土保育地區、農業發展地區第一～三類** | 使用面積 **≥2 公頃** |
| **農業發展地區第四類** | 使用面積 **≥3 公頃** |
| **城鄉發展地區** | 使用面積 **≥5 公頃** |
| **海洋資源地區** | 依**附表四**：輸油（氣）管線（道）及相關設施 **長度 30 公里以上** |

> ⚠ 附表一～三所列使用項目**依所定使用面積另認定**（不套用上表一般門檻）——見下方「六、附表原文」。

## 六、★ 附表一～三 例外情形（2026-08-15 補齊原文）

**同一使用項目在不同分區的門檻不同，且多數比一般門檻更寬鬆或更嚴格——查案時務必先看有無落在例外表內，再套一般門檻。**

### 附表一 國土保育地區（一般門檻 2 公頃）

| 群組 | 使用項目 | 使用面積 |
|---|---|---|
| 農業 | 休閒農業設施（備註一） | **10 公頃以上** |
| 工業 | 特定工業設施（備註二） | **2 公頃以上未達 5 公頃** |
| 維生基礎公共設施 | 水源保護設施、自來水設施、水利設施 | **5 公頃以上** |
| 維生基礎公共設施 | 水源保護設施（水庫及與水庫有關之構造物及設施）、水利設施（防洪排水設施） | **2 公頃以上**（備註三） |
| 特殊 | 國防設施 | **30 公頃以上** |

### 附表二 農業發展地區（一般門檻 2 公頃／第四類 3 公頃）

| 群組 | 使用項目 | 使用面積 |
|---|---|---|
| 農業 | 農作產銷設施、水產設施、畜牧設施、動物保護相關設施、農業改良試驗設施 | **5 公頃以上** |
| 農業 | 休閒農業設施（備註一） | **10 公頃以上** |
| 住商 | **住宅（不含民宿）** | **3 公頃以上** |
| 工業 | 特定工業設施（備註二） | **2 公頃以上未達 5 公頃** |
| 維生基礎公共設施 | 自來水設施、水利設施 | **5 公頃以上** |
| 維生基礎公共設施 | 水利設施（防洪排水設施） | **2 公頃以上**（備註三） |
| 一般性公共設施 | 教育設施（學校） | **5 公頃以上** |
| 能源 | **再生能源設施** | **5 公頃以上** |
| 特殊 | 國防設施 | **30 公頃以上** |

### 附表三 城鄉發展地區（一般門檻 5 公頃）

| 群組 | 使用項目 | 使用面積 |
|---|---|---|
| 觀光 | 運動或遊憩設施（高爾夫球場與其附屬建築物及設施） | **10 公頃以上** |
| 礦業 | 礦業使用及其設施（不含採礦）、營建剩餘土石方處理設施 | **2 公頃以上** |
| 工業 | 特定工業設施（備註一） | **2 公頃以上未達 5 公頃** |
| 維生基礎公共設施 | 廢（污）水處理設施、水利設施（防洪排水設施）之必要性附屬設施 | **2 公頃以上**（備註二） |
| 一般性公共設施 | 廢棄物清除處理設施、殯葬設施（骨灰〔骸〕存放設施、禮廳及靈堂） | **2 公頃以上** |
| 一般性公共設施 | 教育設施（學校） | **10 公頃以上** |
| 能源 | 油（氣）設施、電力設施 | **2 公頃以上** |
| 特殊 | 國防設施 | **30 公頃以上** |

**三表共通備註**：
- **休閒農業設施**：須 10 公頃以上，**且**區內設置休閒農業輔導管理辦法§21①～④之住宿設施、餐飲設施、農產品加工（釀造）廠、農產品與農村文物展示（售）及教育解說中心**達 1 公頃者**（兩條件並存才適用此門檻）。
- **特定工業設施**：指依**工廠管理輔導法§28-10Ⅰ②**規定之工廠使用。
  ★ 城鄉發展地區另有補充：依工輔法§28-10Ⅰ**①** 規定 **5 公頃以上之群聚地區**，其認定基準回歸§3 城鄉發展地區的 **5 公頃**（不適用「2 公頃以上未達 5 公頃」）。
- **必要性附屬設施**（2 公頃列）：以**管理中心、監控室、監測站、停車場、管制站**等設施為限。

## 七、★ 附表五・六 性質特殊認定（2026-08-15 補齊原文）

**性質特殊＝不論面積大小都要走使用許可**，是比面積門檻更早該檢查的一關。

### 附表五 陸域三分區（國土保育、農業發展、城鄉發展）

| 群組 | 使用項目 |
|---|---|
| 農業 | 寵物生命紀念設施（**不含**寵物骨灰灑葬區） |
| 礦業 | 礦業使用及其設施（**限**採礦、石油、天然氣採礦）；土石採取及其設施 |
| 一般性公共設施 | 廢棄物清除處理設施（**限**衛生掩埋場、封閉掩埋場、焚化處理廠）；殯葬設施（**限**公墓、殯儀館、火化場） |
| 能源 | 油（氣）設施（石油煉製及其必要附屬設施） |

**另**：**填海造地**——於**城鄉發展地區海域**進行「築堤」「排水」「填土」「造陸」之行為，屬性質特殊。

### 附表六 海洋資源地區

| 使用項目 | 細目 |
|---|---|
| 再生能源相關設施 | 潮汐能、海洋溫差能、波浪能、海流能、鹽差能、**風力**、**太陽能**發電設施 |
| 土石採取及其設施 | 採取土石 |
| 礦業使用及其設施 | 探採礦（不含石油、天然氣礦）（不含探礦）；石油、天然氣探採礦（不含探礦） |
| 港埠航運 | 港區及其必要附屬設施（**位於現有合法防波堤外廓內者，不在此限**） |
| 環境廢棄物處理或排放設施 | 海洋棄置區 |

## 二、跨分區與線狀設施的特別規則（第四、五條）★

- **第四條 跨分區認定**：
  - 跨**國土保育／農業發展／城鄉發展**任兩者以上：使用面積 **≥2 公頃**。**但**：**休閒農業設施 ≥10 公頃**；**自來水設施、水利設施 ≥5 公頃**；**國防設施 ≥30 公頃**。
  - 跨**海洋資源地區與其他分區**：依§3 面積門檻及附表四長度規定認定。
- **第五條 累計認定與線狀設施排除**：
  - 同一或不同申請人提出**二個以上、申請範圍毗鄰、經目的事業主管機關審認屬同一興辦事業計畫性質**之案件，**累計**使用面積或長度達門檻者，**應申請使用許可**（★防止化整為零規避門檻）。
  - **國土保育、農業發展及城鄉發展地區之線狀設施，使用面積免計入一定規模認定**。

## 三、地方加碼與特殊案型（第六、七條）

- **第六條**：使用面積未達§3門檻，但**經直轄市、縣市國土計畫指定應申請使用許可者，從其規定**——地方可以自行加嚴，不能只查中央標準就自認不用申請。
- **第七條**：**辦理農村社區土地重劃**之申請案件，一定規模以上門檻為**使用面積 ≥3 公頃**。

## 四、性質特殊認定（第八條）

**本法§24Ⅰ所定性質特殊之土地使用**：
- 於**國土保育、農業發展及城鄉發展地區**：依**附表五**認定 → **見下方第七節（原文已補齊）**
- 於**海洋資源地區**：依**附表六**認定 → **見下方第七節（原文已補齊）**

## 五、施行（第九條）

施行日期由中央主管機關定之（★另定施行日型法規）。

## 對衍古的意涵

- **接案第一個判斷就是這篇**：面積達門檻或屬性質特殊項目 → 走 [[國土計畫使用許可申請辦法-重點]] 完整程序；未達門檻 → 可能免走使用許可，但仍須確認**該直轄市/縣市有無自行加嚴指定**（第六條）。
- **★「化整為零」規避門檻在本標準下無效**：第五條的累計認定條款，代表**同一興辦事業計畫分次申請毗連土地**會被合併計算，這與 [[非都市土地使用分區及使用地變更申請案件委辦直轄市縣（市）政府審查作業要點-重點]] 第二點④的「分次申請毗連土地擴大累計達 30 公頃仍歸中央」邏輯一致——兩制對分次申請的態度相同，接案評估不要低估這條的殺傷力。
- **線狀設施免計入面積**是對電力管線、道路等線狀公共設施案型的重要利多，評估此類案件時應主動確認是否適用本排除規定以降低門檻壓力。
- **★ 判斷順序應為「先性質特殊、後面積門檻」**：附表五・六的項目**不論面積都要走使用許可**，若先算面積再查性質特殊，很容易對小面積案件誤判為免辦。衍古常接觸的案型中，**殯葬設施（公墓、殯儀館、火化場）、廢棄物掩埋／焚化、土石採取**都在性質特殊表內。
- **★ 綠能案的分區別差異極大，是本表對衍古最有價值的一條**：**再生能源設施在農業發展地區為 5 公頃**（附表二，比一般 2 公頃寬鬆）；但**海域的風力、太陽能屬性質特殊**（附表六），**不論面積一律要辦**。已完成的 7 案綠能／太陽光電若在新制下重做，適用門檻會與舊制完全不同。
- **住宅（不含民宿）在農業發展地區 3 公頃**（附表二）——這是農業區住宅型案件最直接的門檻依據，且明文排除民宿。
- **特定工業設施是唯一設「上限」的項目**（2 公頃以上**未達 5 公頃**）：三個分區皆同。達 5 公頃以上者不落在此列，另依§3 一般門檻或群聚地區規定判斷——工輔法§28-10Ⅰ① 的 5 公頃群聚地區在城鄉發展地區回歸 5 公頃認定，接特登工廠相關案件時要分清楚是①款還是②款。
