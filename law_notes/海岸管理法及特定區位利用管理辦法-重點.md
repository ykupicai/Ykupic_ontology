# 海岸管理法及特定區位利用管理辦法 重點

## 一、海岸管理法§25：檢具海岸利用管理說明書之義務

> 「在一級海岸保護區以外之海岸地區**特定區位**內，從事**一定規模以上**之開發利用、工程建設、
> 建築或使用性質特殊者，申請人應檢具**海岸利用管理說明書**，申請中央主管機關許可。」

- 第2項（★程序順序）：前項申請**未經中央主管機關許可前，各目的事業主管機關不得為開發、工程行為之許可**。
- 第3項：特定區位、一定規模以上或性質特殊適用範圍與說明書之書圖格式內容、申請程序等，由中央主管機關定之
  → 即**一級海岸保護區以外特定區位利用管理辦法**（D0070234），其重點見本篇後半（同篇合併收錄，未另立筆記）。

## 二、海岸管理法§26：許可條件五款

1. 符合整體海岸管理計畫利用原則
2. 符合海岸保護計畫、海岸防護計畫管制事項
3. **保障公共通行或具替代措施**
4. 對海岸生態環境衝擊採取避免或減輕之有效措施
5. 開發使用自然海岸或填海造地時，應以**最小需用**為原則，並於適當區位採取彌補或復育生態環境損失之措施

第2項：前項許可條件及其他相關事項之規則，由中央主管機關定之。

## 三、辦法§2：特定區位七類

1. 近岸海域
2. 潮間帶
3. 海岸保護區
4. 海岸防護區
5. 重要海岸景觀區
6. **最接近海岸第一條濱海道路向海之陸域地區**
7. 其他經中央主管機關指定之地區

（本條另訂既有合法設施與港埠得排除適用。）

## 四、辦法§3：一定規模之認定基準（★數值門檻）

| 類別 | 門檻 |
|---|---|
| **面積—濱海陸地內太陽光電（僅位海岸防護區陸域緩衝區者）** | 申請或累積利用面積達 **5 公頃** |
| **面積—濱海陸地其他利用** | 申請或累積利用面積達 **1 公頃** |
| 面積—近岸海域 | 申請或累積利用面積達 **5 公頃** |
| 長度—濱海陸地 | 申請或累積利用長度達 **1 公里** |
| 長度—近岸海域 | 申請或累積利用長度達 **5 公里** |
| 高度 | 於**重要海岸景觀區**範圍內申請建築或設置設施高度超過 **10.5 公尺** |
| 樓地板面積 | 建築物總樓地板申請或累積利用面積達 **2,000 平方公尺** |
| 自然狀態改變 | 申請或累積面積達 **330 平方公尺** 或長度達 **100 公尺** |

> ★**太陽光電有專屬門檻**：位於**海岸防護區陸域緩衝區**者為 **5 公頃**（較一般 1 公頃寬鬆）。
> 過去案卷一律寫「面積達 1 公頃」者，遇陸域緩衝區案應重新認定。
> 「**累積**」計算——分期或分割送件不能規避。

## 五、評估製表用法

- 評估事項＝「海岸管理」；判定：
  - **○**：非位於特定區位，或未達一定規模（宜函詢中央主管機關取得書面確認）
  - **△**：位於特定區位且達門檻，須擬具海岸利用管理說明書並取得中央主管機關許可（結果未定）
  - **╳**：位於**一級海岸保護區**（本法系另有禁止規定，非本條適用），或無法符合§26 五款許可條件
- ★**時程硬約束（§25Ⅱ）**：中央主管機關許可**在前**，目的事業主管機關許可**在後**。與出流管制規劃書一樣要倒推排程。
- 實務佐證：彰化芳苑升壓站案（2023）判 △，理由為「本案位於海岸地區特定區位、涉彰化一級海岸防護計畫
  陸域緩衝區，面積大於一公頃，若建物總樓地板達 2,000㎡ 可能需撰寫海岸利用管理說明書」。
