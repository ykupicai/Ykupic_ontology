# 申請開發非都市土地雜項執照書圖文件及審查項目須知 重點

> **這部是什麼**：非都市土地開發案（**山坡地範圍外**，山坡地依其他法令辦理）申請**雜項執照**時，
> 應備的書圖文件清單，以及**哪些項目縣市政府要審、哪些交由技師簽證負責**。全 7 點。
> 山坡地範圍案件走 [[非都市土地非屬山坡地範圍之開發案件申請整地排水計畫與施工管理書圖文件及審查項目須知-重點]] 的姊妹須知（後者名稱雖含「非屬山坡地」但涵蓋整地排水，兩須知常併用）。

## 一、應備書圖文件（第三～六點）

**第三點 四項文件**：①雜項執照申請書 ②土地權利證明文件 ③工程圖樣及說明書 ④**開發許可證明文件影本及許可之開發計畫書**（★這一項證明本案確實走過開發許可審議，缺這份會被要求補正）。

**第四點 申請書應載明**：起造人姓名年齡住址（法人載名稱及事務所）／設計人姓名住址證書字號簽章／基地地址及面積／各項雜項工程名稱數量用途／工程造價／竣工期限。

**第五點 土地權利證明文件**：地籍圖謄本／土地登記簿謄本／**土地使用權同意書**（土地為起造人所有者免附）。

**第六點 工程圖樣及說明書（比例尺門檻表）**：

| 圖說 | 內容 | 比例尺下限 |
|---|---|---|
| 基地位置及現況圖 | 基地位置、鄰地、附近道路情況名稱、建築情況 | — |
| 地盤圖 | 基地方向、地號、境界線、臨接道路名稱寬度、建築物配置 | — |
| 規劃配置圖 | — | **不得小於 1/1,200** |
| 整地平面圖 | 計畫整地範圍及各區位高程 | **不得小於 1/2,000** |
| 整地斷面圖 | 整地前後縱橫斷面 | 橫不得小於 1/1,000、縱不得小於 1/200 |
| 排水系統規劃及管線設計 | — | **不得小於 1/2,000** |
| 排水處理及設計圖 | — | **不得小於 1/200** |
| 道路路線平面圖 | — | **不得小於 1/1,200** |
| 道路路線縱剖面圖 | — | 水平不得小於 1/1,200、垂直不得小於 1/200 |
| 道路橫斷面圖 | **每 20 公尺應有一橫剖面圖** | **不得小於 1/200** |
| 主要構造物詳細設計圖 | — | **不得小於 1/200** |

- 另須**土石方計算書**（整地工程）。
- 給水／污水工程設計圖說（含污水系統規劃、處理放流設施設計）**得於開工前併同目的事業主管機關認可文件送主管建築機關備查**——不必在申請雜項執照時就齊備，是常被漏用的緩衝空間。

## 二、審查分工（第七點）★

> 開發非都市土地雜項執照應由**直轄市或縣市政府審查之項目**如附表一；**其餘項目應由建築師或建築師及專業工業技師簽證負責**，如附表二。

⚠ 附表一、二原文未取得，實務上須向縣市建管單位確認**「政府審」與「技師簽證負責」的確切項目分野**，避免把該由技師簽證負責的項目誤送政府審查（拖時程）或反之（漏審風險）。

## 對衍古的意涵

- **這是「免雜項執照論述」的比對基準**：實務上光電昇壓站、圍籬類小型設施常主張免辦雜項執照，主張前應先確認本須知第三點列的四項文件與工程規模門檻，**若確屬須知範圍內的整地排水道路等雜項工程仍需依本須知備件**，不能逕以「規模小」跳過。
- **比例尺表要當成計畫書圖製作的檢核清單**：11 項圖說各有明確比例尺下限，繪圖階段就要對照，避免送審後才發現比例尺不足被要求重繪。
- **給水污水圖說可延後**——排程時可以善用「開工前備查」這個彈性，不必為了趕送件把還未確定的給水污水方案倉促定案。
- **與整地排水須知的分工**：本須知管**雜項執照**申請的書圖與審查分工；[[非都市土地非屬山坡地範圍之開發案件申請整地排水計畫與施工管理書圖文件及審查項目須知-重點]] 管**整地排水計畫**本身的申請、變更、施工管理與完工申報——兩者常**併案辦理**，接案時一次盤點兩須知的文件需求。
