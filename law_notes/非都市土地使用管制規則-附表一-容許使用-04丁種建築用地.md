# 附表一 容許使用：四、丁種建築用地

總覽與其他使用地：[[非都市土地使用管制規則-附表一-容許使用-總覽]]　條文：[[非都市土地使用管制規則-重點]]

> 欄位：**免經申請許可使用細目**＝不必依本規則申請許可即可使用（仍受附帶條件拘束，見備註二）；**需經許可使用細目**＝需經目的事業主管機關、使用地主管機關及有關機關許可。
> 「〃」＝原表與上一列合併為同一格（同一附帶條件或細目跨列共用）。空白＝原表該格空白。
> 引用時以原檔 `_附表原檔\非都市土地使用管制規則_附表一_容許使用項目及許可使用細目表.pdf` 為準。

## 容許使用項目一覽（8 項）

- （一）工業設施
- （二）工業社區
- （三）再生能源相關設施
- （四）臨時堆置收納營建剩餘土石方
- （五）水庫、河川、湖泊淤泥資源再生利用臨時處理設施
- （六）依產業創新條例第三十九條規定，經核定規劃之用地使用
- （七）廢棄物回收貯存清除處理設施
- （八）交通設施

## （三）再生能源相關設施

| 免經申請許可使用細目 | 需經許可使用細目 | 附帶條件 |
|---|---|---|
| 1.再生能源發電設施 |  | 一、本款各目使用面積一百五十平方公尺以上者，不得位於全國區域計畫規定之沿海自然保護區。<br>二、本款各目符合下列各款規定者，需經目的事業主管機關、使用地主管機關及有關機關許可：<br>(一)使用面積未達一百五十平方公尺，且位於全國區域計畫規定之沿海自然保護區。<br>(二)使用面積零點五公頃以上，且位於全國區域計畫規定之沿海一般保護區。<br>三、工業區外限於興辦工業人設置再生能源相關設施（沼氣發電、一般廢棄物及一般事業廢棄物為再生能源者除外）。 |
| 2.再生能源熱能設施 |  | 工業區外限於興辦工業人設置再生能源相關設施（沼氣發電、一般廢棄物及一般事業廢棄物為再生能源者除外）。 |
| 3.再生能源衍生燃料及其相關設施 |  | 工業區外限於興辦工業人設置再生能源相關設施（沼氣發電、一般廢棄物及一般事業廢棄物為再生能源者除外）。 |
| 4.再生能源輸送管線設施 |  |  |
| 5.其他再生能源相關設施 |  | 工業區外限於興辦工業人設置再生能源相關設施。 |
