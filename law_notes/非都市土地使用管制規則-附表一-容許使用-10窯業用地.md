# 附表一 容許使用：十、窯業用地

總覽與其他使用地：[[非都市土地使用管制規則-附表一-容許使用-總覽]]　條文：[[非都市土地使用管制規則-重點]]

> 欄位：**免經申請許可使用細目**＝不必依本規則申請許可即可使用（仍受附帶條件拘束，見備註二）；**需經許可使用細目**＝需經目的事業主管機關、使用地主管機關及有關機關許可。
> 「〃」＝原表與上一列合併為同一格（同一附帶條件或細目跨列共用）。空白＝原表該格空白。
> 引用時以原檔 `_附表原檔\非都市土地使用管制規則_附表一_容許使用項目及許可使用細目表.pdf` 為準。

## 容許使用項目一覽（6 項）

- （一）窯業使用及其設施
- （二）農作使用（包括牧草）
- （三）水產養殖設施
- （四）再生能源相關設施
- （五）臨時堆置收納營建剩餘土石方
- （六）水庫、河川、湖泊淤泥資源再生利用臨時處理設施

## （一）窯業使用及其設施

| 免經申請許可使用細目 | 需經許可使用細目 | 附帶條件 |
|---|---|---|
| 1.窯業製造 |  | 本款各目位於全國區域計畫規定之沿海自然保護區者，需經目的事業主管機關、使用地主管機關及有關機關許可。 |
| 2.窯業原料或成品堆置場 |  |  |
| 3.自用窯業原料取土 |  |  |
| 4.水土保持設施 |  |  |
| 5.廠房 |  |  |
| 6.單身員工宿舍及其必要設施 |  |  |

## （二）農作使用（包括牧草）

同農牧用地（細目與附帶條件比照該使用地同名項目）。

## （三）水產養殖設施

同農牧用地（細目與附帶條件比照該使用地同名項目）。

## （四）再生能源相關設施

| 免經申請許可使用細目 | 需經許可使用細目 | 附帶條件 |
|---|---|---|
|  | 1.再生能源發電設施 | 限於風力發電、太陽光電之發電設施點狀使用，點狀使用面積不得超過六百六十平方公尺。 |
|  | 2.再生能源輸送管線設施 | 限於線狀使用。 |

## （五）臨時堆置收納營建剩餘土石方

同礦業用地（細目與附帶條件比照該使用地同名項目）。

## （六）水庫、河川、湖泊淤泥資源再生利用臨時處理設施

同農牧用地（細目與附帶條件比照該使用地同名項目）。
