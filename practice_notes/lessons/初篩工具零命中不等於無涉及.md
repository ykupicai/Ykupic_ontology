# 初篩工具「零命中」不等於真的無涉及——重大項目一律交叉核對

## 事故經過

環敏初篩用內政部國土管理署 NGIS（一級25／二級29 共 54 圖層做實際空間套疊）跑七股
某段某地號，對整筆基地回 **0 命中**。但同一筆地：

| 來源 | 氣象法之禁止或限制建築地區（二級 2-25） |
|---|---|
| NGIS 初篩 | **0 命中**（2-25 圖層 polygon 查詢回空） |
| 本機圖層實算 | **涉及 5,176.07 ㎡（7.6%）** |
| 2026-01 同地號官方評估前例 | 亦載涉及（七股氣象雷達站站號 467780 限建範圍） |

若信 NGIS 的 0 命中，就會漏掉「範圍內建築行為須經中央氣象署同意」這個影響設置
條件的重大限制。

## 真相：單一來源的初篩工具會有「整層涵蓋落差」

NGIS **確實有**禁限建類圖層（別的測試點能命中捷運兩側禁建、民航法高度管制），
只是某氣象雷達站這一段範圍未被 2-25 圖層收錄——屬**圖層涵蓋落差、非查詢錯誤**。

這與 [[圖資一律確認版本年度]] 的 NR23（本機自然保留區 106 年版漏收 110 年公告的
龍崎牛埔）**同型但方向相反**：
- NR23：**本機過舊漏、平台有** → 以平台為準、補新版圖資。
- 本案：**初篩工具漏、本機有** → 以本機（＋官方前例）為準、案件層覆蓋補回。
兩者都是「有／沒有」的差異，不是邊界鋸齒或門檻差異，不可忽略。

## 規則

1. **影響設置條件的重大項目**（禁限建、生產區、第一級環境敏感、水源保護）——初篩
   工具回「無涉及」時**一律與本機圖資／eland／同案前例交叉核對**，不可只憑初篩
   0 命中就寫「免辦／無涉及」。
2. **落差方向有兩種、都要防**：本機漏（過舊）、初篩工具漏（單層涵蓋不全）。
   **任一來源說「有」，就以說「有」的那邊為準並查證**。
3. **補救＝案件層覆蓋**：把權威幾何存 `outputs/<案>/環敏/<圖層名>.{shp,geojson}`
   （EPSG:3826），`make_env_map` 會優先採用它出圖與算逐類面積。
4. **交付口徑**：NGIS 初篩是初步評估、非正式套繪（圖台自身聲明），法定認定仍以
   eland 及各主管機關正式查復為準。

> 註：使用者 2026-08-06 就該案定案「**只補這案、暫不改流程**」——指不把自動交叉
> 核對硬加進產線程式碼；但「重大項目須人工交叉核對」本身是通則，不限本案。

## 三種「平台/工具 與 本機 不一致」要分開檢查

| 原因 | 檢查方式 | 對應筆記 |
|---|---|---|
| 版本年度（本機過舊漏整塊） | 檔案日期／分級或分區數／有無 `.prj` | [[圖資一律確認版本年度]] |
| 納入門檻／分級定義（數值差） | 逐分級實算後比對能否用某一級加總對上 | [[平台數值與本機圖資不一致先想圖層門檻]] |
| **初篩工具單層涵蓋落差（有/沒有）** | 重大項目與本機／eland／同案前例交叉核對 | 本篇 |
