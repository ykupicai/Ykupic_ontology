# 同圖層要素重疊時，套疊面積不可逐筆相加

## 情境

環敏套疊圖要算「基地 × 各敏感圖層」的逐類面積。原本的作法是**逐 feature 取交集、
把面積加起來**：

```python
for f in lyr.getFeatures(req):
    inter = geom.intersection(f.geometry())
    agg[key] = agg.get(key, 0.0) + inter.area()   # ← 錯
```

多數圖層的要素彼此不重疊，所以這個錯法一直沒發作。

## 出錯

**NGIS「2-31 大眾捷運系統兩側禁建限建地區」在同一圖層裡有三個互相重疊的面**
（`環狀線`、`環北_二側限建範圍`、`NH-ALING$0$限建線`）。

| 算法 | 結果 | 對錯 |
|---|---|---|
| 逐筆相加 | 8,449 ㎡（50.3%） | **高估四成** |
| 取最大值（NGIS 逐面回報的最大者） | 3,956 ㎡（23.57%） | **低估** |
| **聯集（dissolve 後）** | **6,048 ㎡（36.04%）** | ✅ 正解 |

簡報初版寫的是 23.57%（取最大值），因為 NGIS 是**逐面各回一列**，很容易直覺地
挑最大那筆當代表。

## 正確做法

1. **同一分級內先 dissolve 再算面積**：
   ```python
   agg.setdefault(key, []).append(inter)
   ...
   stats.append([title, key, QgsGeometry.unaryUnion(parts).area()])
   ```
2. **同名圖層要先去重再載入**：NGIS 對同一圖層逐面各回一列，照單全收會把同一份圖資
   載入三次、圖例與逐類面積各出現三次。
3. 凡「逐 feature 累加交集面積」的地方都要回頭檢查——這不只環敏，任何套疊統計皆然。

## 為什麼值得單獨記一條

「相加」在直覺上沒有錯，而且**在不重疊的圖層上永遠給出正確答案**，所以它會一路潛伏到
碰上重疊圖層才爆，而爆的時候**不會報錯、只會給一個看起來很合理的數字**。
這類錯誤沒有測試會攔（面積是對的、只是算錯口徑），只能靠「知道有這件事」。
