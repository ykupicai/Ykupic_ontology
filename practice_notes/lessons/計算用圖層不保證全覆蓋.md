# 政府圖台的「計算用」向量圖層不保證全覆蓋，基地內的破洞要主動找

臺北市都發局有**兩套**都市計畫分區服務：`UrbanPlan2/UrbanPlan2/MapServer/2`（可查詢、
屬性最全，該站 JS 註解即「使用分區服務」）與 `Urban/UrbanPlan/MapServer`（圖磚，
圖層清單裡的「都市計畫使用分區圖」）。

**實錯**：基地加入某筆地號後，計算用圖層在該筆**整筆沒有多邊形**（該點逐點
查詢回 0 筆），但官方彩繪圖與圖磚服務的可查詢層都回「保護區」。若不處理，分區組成
會寫成「基地 96.76% 有分區、保護區 96.58%」——等於**把一筆本來就是保護區的地寫成
無分區**，而那正是本案的變更標的。

## 判準

1. **覆蓋率明顯低於 100% 時，先懷疑圖層破洞**，不要當成「那塊真的沒有分區」。
   本產線的訊號是 `persite_stats` 的 `都市計畫分區_占基地pct`。
2. **補洞要留痕**：只補「基地內未被計算用圖層覆蓋」的缺口，補進來的列標
   `_來源='顯示用圖層(補洞)'`，交付時看得出補了什麼、補多少。
   靜默混入＝把兩種可信度不同的資料混成一筆，違反「不一致先列清單、不過度推論」的原則（原同名筆記不存在，改保留原則文字，避免斷鏈）。
3. 同型推廣：**任何「兩個來源都是官方、但涵蓋不一致」的情況**，先確認是
   「有／沒有」之差還是「值不同」——前者以「有」為準並補齊，後者以更權威者為準。
   對照 [[初篩工具零命中不等於無涉及]]（方向相反、同一類問題）。

引擎：`大量圖資轉換工具\scripts\urbanplan_image.py` 的 `fill_zoning_gaps()`。
