# 「固定語意色」與「依序取色環」混用，會撞成同一個顏色

環敏套疊圖的配色有兩條路：規則層指定的**語意色**（山坡地＝紫 148,103,189）與
未指定者**依命中順序取色環**。實錯：山坡地的語意色**剛好等於色環第 3 格**，而捷運
兩側禁限建沒有語意色、又剛好排在第 3 個命中 → 兩層同色，圖上與圖例都分不出誰是誰。
使用者的回報是「山坡地及捷運兩側禁限建地區顏色太像難以判讀」。

## 判準

- **配色是全域約束，不是逐層決定**：先蒐集所有「已占用顏色」（含語意色），
  取色時跳過已占用者；不可用「命中順序索引對色環取模」，因為索引與語意色互不相關。
- 同型場景：圖例色**從官方彩繪圖取樣**時，也要處理「一個多邊形只取一點會取到圖上
  文字像元」與「大面積分區多邊形延伸到圖框外導致該分區從圖例消失」兩個坑。
- 一般化：**凡是「有些元素被指定、其餘自動分配」的系統，都要先看指定值再分配**，
  否則自動分配遲早撞上指定值。

引擎：`大量圖資轉換工具\scripts\env_color_assign.py`（純模組，回歸測試把撞色寫成斷言）。
