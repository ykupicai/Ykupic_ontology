# 重測後相近段名，同號不是同一宗地——段名查無時一律走新舊地號 API，嚴禁試同號

> **本篇來源**：內容彙整自知識庫既有 skills 的陷阱記載（`parcel-roster-verify`、
> `tcdgis-parcels-to-shp`、`cadastral-map-pipeline`），**非新發生的事故**。
> 實際踩坑的工程細節由當時執行的同仁補充最準。

## 現象

「**甲段第 327 號**」在「**甲一段**」也有地號 327——**但那是別人的地**。

正解是：甲段第 327 號 →（**重測**）→ 甲一段第 **368** 號。

段號在重測時會整段重編，**新舊段之間沒有「同號對應」這回事**。相近段名（甲／甲一、
東振／東振新）只是名字像，號碼系統各自獨立。

## 為什麼比「查無」更危險

「查無地號」會報錯、會被發現。**試同號試中了不會報錯**——平台照樣回一筆合法的地籍，
圖照樣畫得出來，Excel 照樣匯得出來。錯誤會一路靜默地流到出圖與簡報，
**沒有任何一個環節會叫**。

這也是為什麼[[行政區改制更名會讓整段查詢全滅]]那篇特別警告：鄉鎮可以做「去尾比對」
（同一縣市不可能同時有員林鎮與員林市），**段名絕對不行**。

## 鐵律

1. **清冊段名查無、而鄉鎮內存在相近段名時，一律先走新舊地號 API 換算**，
   不准直接在相近段名試同號。
2. **「查無地號」是即時最終回覆，不重試、不換段猜號**（使用者鐵律 2026-07-16）。
3. 段的查詢一律**以段碼為主鍵**，不做段名文字比對（見 [[段的查詢一律以段碼為主鍵]]）。

## 正解工具：新舊地號 API（MOI_API_011，免認證）

`POST https://openapi.moi.gov.tw/WEBAPI/LandNewOldQuery/1.0/QueryLandNo`（陣列，單次 ≤25 筆）

| 參數 | 說明 |
|---|---|
| `UNIT` | 地政事務所代碼 2 碼＝縣市代碼 1 碼＋所序 A/B/C…（不確定哪個所就整組帶，回 null 的就不是） |
| `SEC` | 段代碼 4 碼（直接抄 TCDGIS 地段下拉的 `[xxxx]` 前綴） |
| `NO` | 8 碼＝母號 4 碼＋子號 4 碼零埋（309-1 → `03090001`） |
| `TYPE` | `N` 舊查新／`O` 新查舊 |

回應 `LANDSNCHANGE: [{SEC: 新段代碼, NO: 新8碼, RECEIVEYEAR: 重測年, ...}]`。

- 新段代碼要轉回名稱：回 TCDGIS 該鄉鎮地段下拉找 `[新代碼]`，或用 LISP 段名 API。
- ⚠ **回 `null` ＝無異動紀錄**，意思是該地號真的不存在（分割註銷／合併），
  **不是 API 失敗、不要重打**。依清冊慣例以母號示意出圖並加備註，不硬湊。
