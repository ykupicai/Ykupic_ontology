# 更換申請人的連鎖成本

> **業主說「申請人要換一家公司」時，這不是改個名字而已。**
> 2026-07 補卷發現至少兩案（民雄、將軍）因更換申請人而付出遠超預期的時間成本。
> 這篇的目的：讓下一個接到這句話的人，**在答應之前就把帳算清楚**。

## 一、為什麼換名義這麼貴：名義一致性原則

土地開發案的申請，不是一份文件，而是**一整串以「同一申請人名義」串起來的公文書鏈**。
每一份都指名申請人是誰。換人＝**整串斷掉**。

主管機關的實務要求是：**所有前置同意文件的申請人名義，必須與最終容許／變更編定申請人一致**。
理由很直接——同意函是「同意某某公司做某事」，不是同意這塊土地。

## 二、必然要重做的事（逐項盤點表）

### 2.1 程序面：不是「改名」，是「撤案重送」

實務作法（嘉義民雄案與縣府釐清後之結論）：

> **原申請人發函撤案 → 以新申請人重新向公所／主管機關送件**

意即**回到第一步重排隊**，不是接續原進度。原案已完成的會勘、已取得的公所意見，形式上都不當然沿用。

### 2.2 全部要重新用印的文件

| 文件 | 為何要重簽 |
|---|---|
| **土地使用同意書** | 同意對象是「某公司」 |
| **代辦委託書** | 委託關係主體改變 |
| **申請書** | 申請人欄 |
| **各式切結書** | 切結主體 |
| **專用章授權書** | |
| **村長意見書** | ★ 見下方 2.4，最容易翻車 |
| **鄰地（周邊地主）意見書** | 同上 |

### 2.3 ★ 搭排同意：最貴、最容易漏的一項

農田水利署（工作站）之實務要求：

- 搭排同意文件之**申請人名義須與容許申請人一致**。
- 更換申請人時，**須辦理「搭排變更」**，並**檢附讓渡書**（因原申請已繳費）。
- **不接受僅以佐證文件替代**——不能用「這兩家是關係企業」「已簽讓與協議」等說明蒙混過去。

同理應逐一確認的還有：**水權、養殖登記證、電業／併聯相關文件、建築線指示圖**——凡是「發給某公司」的許可，都要查能否移轉、如何移轉。

### 2.4 在地意見書的隱藏風險

嘉義某室內型農電容許案 的實例：

- **村長意見書曾因村長事後表示「簽章時不知道要設綠能設施」而須重談重簽。**
- **鄰地意見書須涵蓋周邊各地主，不得僅取 1～2 筆。**

換申請人時要重簽這些文件，等同**把在地溝通重跑一次**——而在地方的認知裡，「換了一家公司」往往被解讀成「原本那家出事了」，重簽的難度**高於初次**。**這一段的時間最無法用工時估算。**

### 2.5 顧問契約也要一起變更

衍古端亦須辦理契約變更（民雄案為 2025-08-07 辦理第一次變更、2025-09-24 雙方用印）。**契約變更本身也要跑用印流程**，須納入時程。

## 三、決策前該問業主的四個問題

1. **為什麼要換？**——若是為了融資／售案結構（常見於綠能案），時點能不能延後到取得核准之後？**取得核准後再辦權利移轉，成本遠低於審查中換人。**
2. **新申請人的資格條件符合嗎？**——部分案型對申請人有資格要求（如養殖登記、電業資格、農民身分），換人可能連基本適格都要重建。
3. **前置文件的原簽署人還找得到、還願意簽嗎？**——地主、村長、鄰地地主的意願不是常數。
4. **可接受的時程延誤是多久？**——依民雄案經驗，**從決定換人到重新送件完成，實際耗時約半年**（2025 上半年決定 → 2025-07-23／07-28 才完成第一次提送）。

## 四、如果決定要換：作業順序

1. **先盤點**：把所有已具名之公文書列成清單（含機關、文號、日期、是否可移轉）。**先盤點再動作**，不要邊撤邊發現漏項。
2. **先確認搭排／水權等「需另辦變更」者的程序與所需文件**（讓渡書等），這類最花時間。
3. **與主管機關口頭確認撤案重送之作法**（各縣市承辦見解不一，前述嘉義案即是與縣府釐清後才定案）。
4. **同步啟動在地溝通**，不要等到文件全備才去找村長。
5. **原申請人發函撤案**——放在後段，避免撤了卻卡在別處。
6. **新申請人送件**，並辦理顧問契約變更。

## 五、案型別成本差異：不是每案都套最壞情境（開發許可 route 對照）

上面二、三、四節的「撤案重送＋全套重簽＋半年」是**公所 route（農業容許／漁電）＋自願性換人**的重成本情境。但成本高低會因案型與分工而不同，勿一律套最壞（也勿一律套最好）。

**對照實案——臺南某太陽光電開發許可案**（開發許可、198 筆、深度訪談 2026-08-19）：

- **換人起因是原業主公司遭合併**（法人繼受），非為融資／售案結構主動換人。
- 屬**開發許可（區域計畫委員會）route**：以「**更換申請人文件**」修正版送中央營建署處理，**未撤案重送**（與公所 route 的撤案重送不同）。
- **取得類文件由業主自辦**：土地使用同意書（57 位私地主）、國有地國產署同意、經濟部籌設許可等皆由業主自行處理後提供，衍古端只需調整計畫書文字與辦理契約變更。
- 結果：**顧問端連鎖成本明顯低於民雄／將軍的公所 route 案**。

**決定成本高低的三個變數（答應業主前先定位，不要反射性套用單一情境）**：

1. **換人起因**：合併／法人繼受（被動、關係單純）vs 融資／售案結構（主動、常伴隨資格重建）。
2. **案件 route**：公所 route（農業容許／漁電，實務多為撤案重送）vs 區委會 route（開發許可，可能以更換申請人文件修正版處理）——**務必先向該案主管機關確認換人作法，不同機關見解不一**。
3. **契約分工**：取得類文件（同意書、搭排、籌設許可）由業主自辦 vs 由顧問代辦——落在誰身上，連鎖成本就重在誰身上。

> ⚠ 此對照只有一個開發許可實案佐證，屬**校準本篇、非推翻**：核心原則（名義一致性、前置文件效期、在地溝通重跑）在公所 route 仍成立且仍最貴。

## 六、一句話總結

> **更換申請人不是行政異動，是「撤案重送＋全套文件重簽＋在地溝通重跑」。**
> 在答應業主之前，先問「能不能等到核准後再移轉」——**這一句話可能省下半年**。
