# 農業用地興建農舍與合併門檻（實務）

業主想在**一般／特定農業區的農牧用地**蓋自用住宅時的判斷順序。條文均於 2026-10-02～03 回全國法規資料庫／
農業部法規系統官方原文核對；引用時仍以 [[_核心法規全文-索引]] 與官方原文為準。

## 1. 先確認「變更為建築用地」為何多半走不通

- 管制規則 §27 **附表三**：特定農業區、一般農業區變更為甲～丁種建築用地全為「×」，只能循規則另有規定者。
- 私人實務上只剩兩條零星土地：**§35**（前提＝毗鄰**甲、丙種**建築用地）與 **§35-1**（鄉村區邊緣畸零不整土地）。
  詳 [[非都市土地使用管制規則-重點]] 的「附表三與零星土地」節。
- 常見誤判：基地緊鄰鄉村區就以為能變更——鄉村區多是**乙種**建築用地，§35 前提不成立；§35-1 第三款
  （≤0.5 公頃）以**所在連續農業用地整塊**認定，不是只看申請的那幾筆。

## 2. 改走興建農舍（容許使用，不必變更編定）

| 路徑 | 門檻 | 依據 |
|---|---|---|
| 一般（89.01.04 後取得） | 農民身分、戶籍與土地同縣市、**土地取得及戶籍均滿二年**、無自用農舍、確供農業使用；**「該筆」農業用地 ≥0.25 公頃** | 農發條例§18Ⅰ、農舍辦法§2 |
| 89.01.04 前取得之農地 | 仍須**為農民**、無自用農舍、為所有權人且確供農業使用（農舍辦法§3 準用§2Ⅰ④⑤）；依相關土地使用管制及建築法令申請，**不受 0.25 公頃與取得／戶籍滿二年限制** | 農發條例§18Ⅲ、農舍辦法§3 |

- **「該筆」是單筆**，同一人多筆分散不能合計。不足者可把相鄰土地**合併為一筆**：地籍測量實施規則§224
  要求同一地段、地界相連、使用性質相同；所有權人不同附全體協議書、有抵押權附抵押權人協議書。
- ⚠ 合併後「取得滿二年」如何起算，法規未明定——**洽縣市農業局確認**後再對業主承諾。
- ⚠ 取得日要看**謄本所有權部**。地籍查詢回的「登記日期」常是地籍圖重測（彌陀案兩筆皆 86.05.13 重測），
  不是取得日。

## 3. 規模與限制

- 建築面積 ≤ 耕地 10%、最大基層 ≤330㎡、總樓地板 ≤495㎡、≤3 層且 ≤10.5m（建管辦法§5）；
  農舍用地 ≤10%、其餘農業經營用地須為完整區塊且 ≥90%（農舍辦法§9）。約 0.33 公頃以上時 10% 即超過 330㎡。
- **同一筆農業用地僅能興建一棟農舍**；已申請者套繪管制、未解除不得分割（§9、§12）。基地上若已有建物，
  先查是否為已套繪之農舍——是的話合併後也不能再申請。
- 臨路：臨接寬 6m 以下道路自中心線退讓 3m；以私設通路連接者寬度依長度 2／3／5m（建管辦法§11）。
  現況巷道常坐落私有地而非交通用地，能否指定建築線須主管建築機關認定。

  0.3466 公頃→農舍△（待資格、取得日、既有建物、建築線）。見 某農舍住宅評估案。
